# Agicap for .NET
An [Agicap](https://agicap.com) API client library for [C#](https://learn.microsoft.com/en-us/dotnet/csharp).
	
## Quick start
Install the latest version of **Agicap for .NET** with [NuGet](https://www.nuget.org) package manager:

```shell
dotnet package add Mc2it.Agicap
```

For detailed instructions, see the [installation guide](Installation.md).
